Add a new table format "dokuwiki" to tabulate. DokuWiki tables use "^" as the cell separator for header rows and "|" for data rows, e.g. "^ name ^ qty ^" then "| apple | 3 |", with no horizontal rule lines. Column alignment should be expressed with DokuWiki padding conventions (two spaces on the side opposite to the alignment; centered = two spaces on both sides). Literal "|" and "^" characters inside cells must not break the table. Register it wherever table formats are listed (including docs/README if they list formats), add tests in test/test_output.py, and run: /opt/venv/bin/python -m pytest test/test_output.py -q -k dokuwiki
